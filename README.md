# Matheos

Plain-text calculation documents for structural engineers: Markdown prose plus unit-aware math
blocks, checked and rendered to a printed report. The editor runs at
**https://matheos.fly.dev** (editor at `/app/`).

This repository is the public front door of the project while the source stays private.

- **Found a bug or want a feature?** [Open an issue](https://github.com/Suharevillya/matheos-issues/issues/new).
  Paste the `.mth` text that shows the problem (or the smallest piece of it), say what you
  expected, and add a screenshot if the editor looks wrong.
- **Writing `.mth` documents?** [SKILL.md](SKILL.md) is the authoring guide: grammar, units,
  checks, conditionals, vectors, loops, tables, drawings, plots, and the mistakes that cost a
  round-trip.

Matheos is built by [NODETEC](https://nodetec.fi) next to FrameLab.
